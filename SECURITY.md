# Security / 安全

## English

LabVault Scout is designed to inspect untrusted research directories without modifying source files.

Please report security issues privately through GitHub's security reporting facilities when available. Do not include sensitive research data in reports.

The project does not intentionally execute scanned files, macros, scripts, or embedded application code.

## 中文

LabVault Scout 的设计目标是在不修改源文件的情况下检查可能不受信任的科研目录。

发现安全问题时，请优先使用 GitHub 提供的私密安全报告渠道。报告中不要包含敏感科研数据。

本项目不会主动执行被扫描文件、宏、脚本或嵌入式应用代码。
